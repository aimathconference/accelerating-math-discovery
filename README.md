# accelerating-math-discovery

Carl McTague. I teach at Boston College. I work on formally verified algorithms for computational homotopy theory. I'm developing an efficient new data structure and algorithm for computing spectral sequences, which has led to a state-of-the-art algorithm for computing Curtis tables. (Despite the algebra growing exponentially, the number of required tag calculations appears to grow subexponentially.)

I recently autoformalized a theorem of mine on the arithmetic of binomial coefficients with a PC
[Autoformalization with a PC](https://www.mctague.org/carl/blog/2026/10/06/autoformalization/)

Idea for project: 

Risch’s algorithm to compute the antiderivative of any elementary function or else emit a certificate that it has none – implemented and formally verified in Lean. This would be an excellent use of AI: despite being understood in principle for decades, this fundamental and useful algorithm has yet to be fully implemented. A formally verified implementation in Lean would be useful in its own right as well as serve as a reference implementation for other computer algebra systems.
